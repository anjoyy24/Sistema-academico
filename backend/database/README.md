# Base de datos

Esta carpeta contiene los scripts SQL del proyecto.

- `schema.sql`: propuesta opcional con estudiantes, docentes, tareas, entregas y feedback. Está disponible en `US-01-02` y debe validarse antes de usarla en una base nueva.
- `seed.sql`: reservado para futuros datos ficticios de desarrollo; todavía no existe.

La demo de `US-01-02` utiliza memoria y no necesita PostgreSQL ni ejecutar el esquema. En `main` esta carpeta solo contiene la documentación base.
